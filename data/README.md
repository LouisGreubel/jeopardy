# Generated clue data

`manifest.json` is the entry point for the browser data loader.

- `round1/*.json` contains complete Round 1 five-clue category instances.
- `round2/*.json` contains complete Round 2 five-clue category instances.
- `final/*.json` contains Final Jeopardy clues.

Each shard uses schema version 2 and contains an `items` array. The manifest records every shard's relative path, record count, byte count, and SHA-256 hash.

The data files are generated by `tools/build_data.py`. Do not edit them by hand; update `clues.xlsx` or the documented conversion rules and rerun the converter.
